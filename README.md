# Bulls and Cows

Браузерная игра «Быки и коровы», разработанная на TypeScript в рамках обучения RS School.

## Описание

Компьютер генерирует секретное число из неповторяющихся цифр. Задача игрока состоит в том, чтобы угадать его.

После каждой попытки отображаются:

- Быки: правильные цифры на правильных позициях.
- Коровы: правильные цифры на других позициях.

Игра завершается, когда все цифры угаданы.

## Возможности

- Выбор системы счисления: 2, 8, 10 или 16.
- Выбор длины секрета от 2 до 6 цифр с учётом системы счисления.
- Проверка корректности ввода.
- Подсчёт быков и коров.
- История попыток.
- Таблица рекордов с сохранением в localStorage.
- Возможность начать новую игру.
- Адаптивный интерфейс.

## Архитектура

Игровая логика находится в `src/game`.

Браузерный интерфейс реализован в `src/main.ts`.

Стили находятся в `src/style.css`.

Описание архитектурных решений приведено в `DESIGN.md`.

## Тестирование

Для проверки игровой логики используется Vitest.

Реализованы автоматические тесты для:

- evaluateGuess
- isValidGuess
- generateSecret
- createDigitValidator
- countPossibleSecrets
- checkGuess
